## 🚀 Quick Start Deployment (45 minutes)

### Step 1: Deploy Backend to Railway (15 min)

```bash
# 1. Go to https://railway.app
# 2. Create new project
# 3. Add PostgreSQL database
# 4. Create environment variables:

PORT=3001
TOKEN_SECRET=your-secret-$(openssl rand -hex 16)
ENCRYPTION_KEY=your-key-$(openssl rand -hex 16)
ADMIN_KEY=YourAdminKey2026!$(openssl rand -hex 8)
DATABASE_URL=postgresql://... (auto-generated by Railway)

# 5. Upload akfu-backend.ts
# 6. Deploy
# 7. Get your API URL (e.g., akfu-api.up.railway.app)
```

### Step 2: Initialize Database (5 min)

```bash
# Replace YOUR_API_URL with your Railway URL
# Replace YOUR_ADMIN_KEY with your admin key

curl -X POST "https://YOUR_API_URL/admin/setup-db?admin=YOUR_ADMIN_KEY" \
  -H "Content-Type: application/json"

# Response should show: "tables_created": 18
```

### Step 3: Deploy Frontend to Vercel (20 min)

```bash
# 1. Go to https://vercel.com
# 2. Create new project from GitHub
# 3. Select your repo (or create new Next.js project)
# 4. Add environment variables:

NEXT_PUBLIC_API_URL=https://YOUR_API_URL
NEXT_PUBLIC_ENVIRONMENT=production

# 5. Deploy
# 6. Get your frontend URL (e.g., akfu-studios.vercel.app)
```

### Step 4: Test Everything Works (5 min)

```bash
# 1. Visit: https://YOUR_FRONTEND_URL
# 2. Click "Register"
# 3. Create account with test email
# 4. Should redirect to dashboard
# 5. Done! ✅
```

## ✨ Key Features

### Unified Login
Users login once to AKFU and access all services (Higgsfield, Suno, ElevenLabs, etc.) without re-authenticating.

### Persistent Sessions
No need to re-login to external services. AKFU manages all sessions server-side.

### Unified Dashboard
All provider accounts, balances, and usage visible in one place.

### Affiliate Tracking
Earn credits when users sign up through your affiliate links.

### Automatic Credit Deduction
Credits are automatically deducted from unified balance when generating content.

### Complete Workflow
Write script → Create characters → Design outfits → Generate video - all in AKFU.
